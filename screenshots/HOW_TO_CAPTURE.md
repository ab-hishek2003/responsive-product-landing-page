# How to capture these screenshots (2 minutes)

1. Open `index.html` in Chrome.
2. Open DevTools (F12 or Cmd+Opt+I) → click the device toolbar icon (Ctrl/Cmd+Shift+M).
3. Set the viewport size and use DevTools' "Capture screenshot" (⋮ menu in the device toolbar):
   - Desktop: 1440 x 900 → save as `desktop.png`
   - Tablet:  768 x 1024 → save as `tablet.png`
   - Mobile:  375 x 812  → save as `mobile.png`
4. Drop the three PNGs into this `screenshots/` folder — the README already references them.
